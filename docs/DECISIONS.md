# Decisions

Append-only. Newest last.

- 2026-11-14. Plan approved by the owner. Root commit `Added design plan` pushed to `main` by the orchestrator under the owner's identity, as the owner allowed. All later work is on `feature/museum`.
- 2026-11-14. Models. Test, code, and merge agents run on the newest Sonnet 5 release at medium effort. The review agent runs on the newest Opus 5 release at medium effort.
- 2026-11-14. Language split. Game code under `src/` is TypeScript. Scripts under `tools/` are plain ES modules (`.mjs`) so that git hooks run with bare `node` and no build step. Tests are TypeScript under `tests/`, run by Vitest.
- 2026-11-14. Coverage gate scope. The "every new line is executed by a test" gate applies to `src/` and to library modules under `tools/**/lib/`. Thin hook entry scripts are exercised by tests that spawn them as child processes.
- 2026-11-14. The merge agent does not push. The orchestrator pushes `feature/museum` after auditing each commit.
- 2026-11-14. Style mockups are kept outside the repository in an untracked `mockups/` folder, excluded through `.git/info/exclude`.
- 2026-11-14. Owner request: quality tooling. Linter is ESLint, style checker is Prettier, mutation testing is StrykerJS with the Vitest runner. `npm run check` runs linter, style checker, and type checker. From the item that adds it onward, the orchestrator runs mutation testing on the product files each item changes; CI runs it in full with a break threshold of 80.
- 2026-11-14. Split M1-03 in two. Its irregular-verb tests passed on arrival only because the validator still accepted everything, so they could not be shown red. The rejection rule is now M1-03 and the irregular-verb list is M1-03b, each with its own red, green, and commit.
- 2026-11-14. For the Codex continuation, GPT-6.1 Sol at medium effort fills the test, code, and merge roles. GPT-6 Astra at medium effort fills the review role. The Sonnet 5 and Opus 5 families are unavailable on this runner.
- 2026-11-14. Flaky tooling tests. The tests that launch ESLint, Prettier, `npm run check`, and `npm install` ran close to the test runner's 5-second default (the combined check took 4.9 s alone) and failed in 9 of 9 runs when three suites ran at once. Added M1-16 to give those tests a 60-second limit. It is a test-only change and gets its own commit.
- 2026-11-14. Resumed after a continuation on another runner. The orchestrator audited all commits since the root, then finished the interrupted item M1-15 from its uncommitted test and code after re-verifying red and green itself, rather than stashing and restarting it.
- 2026-11-14. Content security policy constraints for later items. The policy is `default-src 'self'` plus NASA images. Consequences: (a) the build must not inline assets as `data:` URIs, so set Vite's `build.assetsInlineLimit` to 0 when the first asset is imported; (b) no `style="…"` attributes in markup or via `setAttribute`; set `element.style` from code instead; (c) if audio is ever played or exported through `blob:` URLs, `media-src` must gain `blob:` in a tested item. Framing and base-tag protections are split out as M2-03b.
- 2026-11-14. Replaced M2-06. A separate build step in the pull request checks would be redundant: `npm test` already runs `npm run build` through `tests/site/build.test.ts`, so CI builds the site on every pull request. M2-06 is now an integration test that the smoke check passes against the real build output. It is expected to pass on arrival and be committed as a test-only change.
- 2026-11-14. M3 uses the SVS card's `instance.id` as the identity. The live root response contains nine gallery cards, fifteen detail-page cards, and one embedded media card. Gallery and detail-page IDs resolve through `/api/<id>`. Link and media cards carry embedded media metadata and can have IDs with no page API endpoint.
- 2026-11-14. Featured movie sampling uses local `ffmpeg` and `ffprobe` executables on `PATH` for manual ingest. It reads the first video stream only, uses authenticated SVS HTTPS, and outputs 48 RGB frames at 320×180. The unit suite uses local fixture executables and does not require FFmpeg or contact NASA. Portable macOS FFmpeg builds may need `SSL_CERT_FILE=/etc/ssl/cert.pem` to use the system certificate bundle.
- 2026-11-14. A preflight of the selected listening images found that SVS 5072's API main image returns HTTP 404. The official page publishes the same January–December single-year view under a new filename. M3-21b records that exact replacement without altering the captured NASA response.
- 2026-11-14. Review of the selected views found that SVS 4285 labels its frozen and liquid precipitation colour bars in alt text. Their filenames contain `snowbar` and `rainbar`. M3-18b extends the auxiliary-image filter to use that NASA metadata.
- 2026-11-14. The gallery API transposes the reported width and height of some embedded images. PNG headers show that seven Worldview originals are 4096 pixels wide. Ingest keeps those artifacts, records the original NASA URL and verified size, and uses the local WebP when no published variant meets the 3840-pixel remote width cap.

- 2026-11-14. The single processed-media upload disconnected repeatedly during Git transfer. M3-23a through M3-23t stage the same verified files in smaller commits. M3-23 publishes the complete catalog once all media are present.
- 2026-11-14. Use `--ignoreStatic` for targeted mutation runs during iteration. At each phase boundary run the full test suite and full mutation run, including static mutants.
- 2026-11-14. The owner asked to parallelise development and keep the full project scope even if it runs past midnight. Independent items use isolated worktrees with one writer per worktree. Each item keeps its own red, green, review, and commit on `feature/museum`.
- 2026-11-14. Second orchestrator lane. While M4 is being built on `feature/museum`, a second orchestrator builds M5 (audio core) on branch `feature/museum-audio` in its own worktree, touching only `src/audio/`, `tests/audio/`, the M5 section of the backlog, and this log. It pushes only that branch. The branch is rebased onto `feature/museum` and fast-forwarded into it when M4 is quiet, so the single pull request and the linear history are kept. Test, code, and merge workers on this lane run on the Sonnet 5 family at medium effort; review runs on the Opus 5 family at medium effort.
- 2026-11-14. `euclideanRhythm` is defined for 0 ≤ pulses ≤ steps. A caller that derives the pulse count from data (the Wildfires room turns burned area into pulses) must clamp it to that range in its own tested item.
