- 2026-11-14. Owner request: quality tooling. Linter is ESLint, style checker is Prettier, mutation testing is StrykerJS with the Vitest runner. `npm run check` runs linter, style checker, and type checker. From the item that adds it onward, the orchestrator runs mutation testing on the product files each item changes; CI runs it in full with a break threshold of 80.
- 2026-11-14. Split M1-03 in two. Its irregular-verb tests passed on arrival only because the validator still accepted everything, so they could not be shown red. The rejection rule is now M1-03 and the irregular-verb list is M1-03b, each with its own red, green, and commit.
- 2026-11-14. For the Codex continuation, GPT-6.1 Sol at medium effort fills the test, code, and merge roles. GPT-6 Astra at medium effort fills the review role. The Sonnet 5 and Opus 5 families are unavailable on this runner.
- 2026-11-14. Flaky tooling tests. The tests that launch ESLint, Prettier, `npm run check`, and `npm install` ran close to the test runner's 5-second default (the combined check took 4.9 s alone) and failed in 9 of 9 runs when three suites ran at once. Added M1-16 to give those tests a 60-second limit. It is a test-only change and gets its own commit.
- 2026-11-14. Resumed after a continuation on another runner. The orchestrator audited all commits since the root, then finished the interrupted item M1-15 from its uncommitted test and code after re-verifying red and green itself, rather than stashing and restarting it.
- 2026-11-14. Content security policy constraints for later items. The policy is `default-src 'self'` plus NASA images. Consequences: (a) the build must not inline assets as `data:` URIs, so set Vite's `build.assetsInlineLimit` to 0 when the first asset is imported; (b) no `style="…"` attributes in markup or via `setAttribute`; set `element.style` from code instead; (c) if audio is ever played or exported through `blob:` URLs, `media-src` must gain `blob:` in a tested item. Framing and base-tag protections are split out as M2-03b.
- 2026-11-14. Replaced M2-06. A separate build step in the pull request checks would be redundant: `npm test` already runs `npm run build` through `tests/site/build.test.ts`, so CI builds the site on every pull request. M2-06 is now an integration test that the smoke check passes against the real build output. It is expected to pass on arrival and be committed as a test-only change.
